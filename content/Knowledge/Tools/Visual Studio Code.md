# Extensions
## Black Formatter
A Visual Studio Code extension with support for the Black formatter to format Python 🐍 files. The extension ships with `black=24.8.0`.
For more details, visit the [VS code Marketplace](https://marketplace.visualstudio.com/items?itemName=ms-python.black-formatter&ssr=false#overview)

> [!TIP] Formatting of jupyter notebooks
> - MacOS: `Option + Shift + F`
> - Windows: `Alt + Shift + F`

For more details, refer [How to Format Jupyter notebook in VSCode](https://stackoverflow.com/questions/65747615/how-to-format-jupyter-notebook-in-vscode)
