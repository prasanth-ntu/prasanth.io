# Macbook Shortcuts
## Code Folding
- **Fold innermost uncollapsed region at the cursor:** ⌥ + ⌘ + [
- **Unfold collapsed region at the cursor:** ⌥ + ⌘ + ]

- **Fold all regions in the editor:** ⌘ + R , ⌘ + 0 (zero)
- **Unfold all regions in the editor:** ⌘ + R , ⌘ + J

# Keyboard Shortcuts
