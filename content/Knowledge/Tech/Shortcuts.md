# VS Code
## Keyboard Shortcuts
### Code Folding and Unfolding
Source: [How do I fold/collapse/hide sections of code in Visual Studio Code?](https://stackoverflow.com/questions/30067767/how-do-i-fold-collapse-hide-sections-of-code-in-visual-studio-code)

[Folding](https://code.visualstudio.com/docs/editor/codebasics#_folding) has been rolled out and is now implemented since Visual Studio Code [version 0.10.11](https://code.visualstudio.com/updates/vFebruary). There are these keyboard shortcuts available:

- **Fold** folds the innermost uncollapsed region at the cursor:
    - Ctrl + Shift + [ on Windows and Linux
    - ⌥ + ⌘ + [ on macOS
- **Unfold** unfolds the collapsed region at the cursor:
    - Ctrl + Shift + ] on Windows and Linux
    - ⌥ + ⌘ + ] on macOS
- **Fold All** folds all regions in the editor:
    - Ctrl + K, Ctrl + 0 (zero) on Windows and Linux
    - ⌘ + K, ⌘ +0 (zero) on macOS
- **Unfold All** unfolds all regions in the editor:
    - Ctrl + K, Ctrl + J on Windows and Linux
    - ⌘ + K, ⌘ + J on macOS
