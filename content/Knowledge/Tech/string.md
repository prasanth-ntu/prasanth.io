# String constants
- `string.asci_lowercase`
	- The lowercase letters `'abcdefghijklmnopqrstuvwxyz'`. This value is not locale-dependent and will not change.
```python
import string
alphabet = string.ascii_lowercase
print (alphabet)
```

```output
abcdefghijklmnopqrstuvwxyz
```
